How to get your GitHub Token in 1 minute:
1. Go to GitHub Settings -> Developer Settings -> Personal access tokens (classic).
2. Click "Generate new token (classic)".
3. Tick the "repo" checkbox scope (gives write permissions to push documents.json).
4. Click "Generate token" at the bottom, copy the code and paste it above.
* Your token is securely saved in your browser's private storage (localStorage) and never exposed.
